# Приклад електричного проєкту

`complete-electrical-demo.ecad` демонструє два аркуші, спільний пристрій із кількома функціями, стабільні електричні кола, клемник, кабель із жилами, бібліотечні варіанти та міжсторінкове посилання.

Дані компонентів і кабелю навчальні та потребують перевірки перед використанням у реальному проєкті.

Назва `complete-electrical-demo` історична: приклад демонструє структуру електричних даних, запроваджену у 0.17; файл перезбережений у schema 13 для 0.18, а не завершену перевірену схему. Аудит генератора до і після завантаження в EditorSession дав 14 повідомлень ERC: 6 непідключених контактів, 3 вільні кінці провідників, 5 символів без бібліотечного варіанта. Міжсторінкове посилання поки графічне й не об’єднує електричні кола. Наявний автоматичний check перевіряє моделі та round-trip, а не ERC=0. Завершення прикладу включене в milestone 0.20 у [PLAN](../../PLAN.md).
