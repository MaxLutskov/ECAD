# ECAD 0.19 — робочий простір

Версія застосунку 0.19; формат документа 13 і бібліотеки 1 не змінені. Дата: 2026-09-16.

## Що змінилося

- Верхнє меню, компактна панель дій із власними векторними значками та вертикальні інструменти малювання. Активний інструмент позначається рамкою; підказки містять назву й клавішу.
- Вкладки аркушів над полотном. Панелі «Аркуші», «Бібліотеки», «Пристрої / кола», «Властивості», «ERC» можна переносити між лівою, правою та нижньою областями через контекстне меню вкладки. Межі панелей перетягуються; «Вигляд» дозволяє приховати/повернути панель і скинути розкладку.
- Розкладка зберігається у `LocalApplicationData/ECAD/workspace.json`, окремо від креслення. Пошкоджені/невідомі записи ігноруються. Плаваючих вікон панелей немає.
- `Ctrl+Shift+P` відкриває пошук за назвою, категорією або ID команди. Меню, кнопки, контекстне меню й клавіатура використовують ті самі команди та CanExecute. L/C/R/D/P/A збережені; введення тексту й чисел не перемикає інструменти.
- Інспектор підтримує спільну назву та зміщення кількох об’єктів, висоту кількох текстів; різні значення позначені явно. Застосування — одна транзакція Undo; неправильні числа не змінюють документ.
- Бібліотечна панель шукає символи та варіанти компонентів. Подвійний клік або Enter вмикає вставлення; варіант і його фізичне виконання зберігаються у вставленому символі.
- F7 запускає ERC у фоні. Вибір повідомлення відкриває потрібний аркуш, центрує й виділяє елемент. Повідомлення без графічного елемента пояснюються текстом. Зміна документа під час перевірки відхиляє застарілий результат.
- Читання/запис файлів виконуються у фоні, файлові операції не накладаються одна на одну. Є команда скасування; запис перевіряє скасування до заміни файлу. ERC/читання скасовуються на безпечній межі, їх результат не застосовується.
- Світла й темна теми оболонки; папір залишається білим. Помилки залишаються в повідомленні до закриття, доступний журнал; неочікувані помилки мають ID для пошуку у журналі.

## Архітектура та перевірки

`WorkspaceCommands` — реєстр команд/ICommand; `WorkspacePanels` — реєстр панелей і layout. `CanvasRenderer` читає документ/selection/viewport, не володіє інструментами або session. DrawingCanvas керує взаємодією та preview. EditorSession має окремі події content/selection/active page; інспектор пропускає повторні події без змін. Спільне редагування винесено у Core/Application/SelectionProperties. Назви основних команд містяться у resx, semantic resources визначають кольори оболонки.

Перевірка: `./scripts/Verify.ps1`. Набір містить 133 сценарії, з них нові перевіряють команди/CanExecute, текстовий фокус, вкладки, бібліотечну ідентичність, multi-selection/Undo, layout/пошкоджені settings, ERC-навігацію, палітру команд, скасування файлів та headless масштабування 100/150/200% при ширині 900 DIP. Результати зображень — `tmp/checks/workspace-*.png`. Локальний Release пройшов з 0 warnings/errors. [GitHub Actions 35060315223](https://github.com/MaxLutskov/ECAD/actions/runs/35060315223) для коміту `d2ff8ce` успішний на Windows (2 хв 42 с) та Ubuntu 24.04 (42 с): по 133 checks і перевірка пакування. Обидва CI-прогони використовують stable .NET 10.

Пакети: `output/v0.19/win-x64` та `output/v0.19/linux-x64`; потрібен .NET 10 Runtime. Приклади знаходяться в Projects/Libraries; старі папки пакетів не видаляються. Версія Windows binary — `0.19.0.0`, ProductVersion — `0.19+d2ff8ceb32a4735897aa9d2672902b6d58638ad7`.

## Межі та ручне приймання

Це функціональна збірка 0.19. Headless-перевірки не є ручним прийманням нативного вікна на Windows/Ubuntu. На обох системах ще потрібно пройти сценарії нижче при 100/150/200%:

1. Відкрити приклад, перемикати вкладки, змінити розміри панелей, перенести/приховати/повернути їх і перезапустити програму.
2. Намалювати мишею та числом, перевірити Tab/Enter/Esc, вибрати рамкою кілька об’єктів, застосувати властивості й Undo/Redo.
3. Знайти й вставити бібліотечний варіант, перевірити F7 та перехід до елемента, save/open.
4. Перевірити контраст, системні діалоги, довгі українські назви й фокус клавіатури на реальному дисплеї.

Редактори бібліотеки й повної електричної моделі поки відкриваються діалогами; панелі дають пошук та навігацію. Інспектор ще має code-behind; усі domain collections не переведені на immutable/read-only API. Ресурсами охоплені основні команди, повний переклад старих діалогів не вводився. Тема поки не зберігається між запусками. Ці обмеження не означають реалізації повного electrical workflow: його наступний етап — 0.20; шари залишаються 0.23.
