# Приклад електричного проєкту

`complete-electrical-demo.ecad` демонструє два аркуші, спільний пристрій із кількома функціями, стабільні електричні кола, клемник, кабель із жилами, бібліотечні варіанти та міжсторінкове посилання.

Дані компонентів і кабелю навчальні та потребують перевірки перед використанням у реальному проєкті.
