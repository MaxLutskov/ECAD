# ECAD

Початковий кросплатформний редактор креслень на C# / .NET 10 / Avalonia 12.1.2. Release build та 123 автоматичні перевірки пройшли GitHub CI на Windows і Ubuntu 24.04 LTS. Ручне desktop-приймання Ubuntu, включно HiDPI, ще попереду.

## Що працює зараз

Версія **0.18** — функціональний прототип. Працюють геометрія, числове введення, розміри, вибір/групи, символи, провідники, каталоги та базові багатосторінкові креслення. Є моделі пристроїв, функцій, кіл, клем і кабелів, але їхні редактори та ERC неповні. Навігатор `⚡` містить списки й редактор призначень клем/жил; міжсторінкові посилання не об’єднують кола. Редактор шаблонів штампів, компонування щита, PDF/друк/BOM, recovery та шари ще відсутні. Відомі дефекти описані в [аудиті](docs/AUDIT.md).

Це ранній ECAD-прототип. Спільні кінці провідників належать одному колу; перетин об'єднує кола лише через явний вузол. Вбудовано 9 IEC і 3 ANSI-чернетки: контакти, котушки, клема, запобіжник, автомат, трифазний двигун, PE та частотний перетворювач. Перевірка знаходить непідключені контакти, вільні кінці й точні дублікати символів. Відповідність конкретним редакціям стандартів ще потребує окремої перевірки.

## Запуск із вихідного коду

Потрібен .NET 10 SDK; перше відновлення залежностей потребує мережі. Виконувати з кореня репозиторію:

```sh
dotnet restore ECAD.slnx --configfile NuGet.Config
dotnet run --project src/ECAD.Desktop/ECAD.Desktop.csproj --no-restore
```

У поточному робочому середовищі залежності вже завантажено. Для запуску з коду на Windows можна використати `run.ps1`. Готовий пакет запускається файлом `Start ECAD.cmd`; технічні файли вже розкладено правильно, переміщати їх окремо не потрібно.

На Linux виконуються ті самі команди dotnet. Системні залежності та підтримувані дистрибутиви описані в [документації Avalonia](https://docs.avaloniaui.net/docs/platform-specific-guides/linux). Веб і мобільні збірки ще не створювалися.

## Готові збірки

Пакувальник читає версію з `Directory.Build.props`. Повторна збірка створює окрему папку `output/v<version>-build-<час>-<id>` і не видаляє попередні `Projects/Libraries`. Параметр `-Version`, якщо заданий, має збігатися з props.

Пакети 0.18: `output/v0.18/win-x64` та `output/v0.18/linux-x64`. Потрібен .NET 10 Runtime відповідної платформи (SDK теж підходить). Пакети не входять у Git; їх можна зібрати через `./build-packages.ps1`.

- Windows: запустити `Start ECAD.cmd` у корені папки `win-x64`.
- Ubuntu x64: у корені `linux-x64` виконати `sh start-ecad.sh`.

Структура пакета:

- `Projects` — стандартна папка збереження та відкриття `.ecad`;
- `Libraries` — стандартна папка імпорту й експорту `.ecadlib`, разом із двома прикладами;
- `App` — виконувані та технічні файли програми;
- `README.txt` — коротка інструкція для користувача.

Обидві збірки скомпільовані успішно. Linux-пакет ще не проходив фактичний запуск. Це попередні збірки для перевірки креслення, а не готовий інструмент для випуску електричних схем.

## Коротка перевірка користувачем

1. Кнопкою `Тип` обрати провідник або графіку, натиснути «Лінія / провідник» та клацнути початок. Для способу «точка–точка» потягнути курсор і клацнути кінцеву точку.
2. Для способу «точка–розміри» після першого кліку просто набрати `12,3` або `12.3`, натиснути Tab, набрати `30`, натиснути Enter. Лінія матиме 12,3 мм і кут 30° незалежно від сітки. 0° — праворуч; +90° — вгору; від'ємні кути також підтримуються. Можна задати лише довжину або лише кут; другий параметр визначає курсор. Порожнє поле звільняє параметр, 0 не є допустимою довжиною.
3. Для вільного креслення просто клацнути кінець без числового вводу. Для точного прямокутника після першого кута ввести ширину → Tab → висоту → Enter. Для точного кола після центра ввести радіус → Enter; щоб задати діаметр, перейти Tab у поле діаметра. Подвійний клік по лінії, прямокутнику або колу відкриває ті самі параметри для редагування.
4. У режимі «Вибір / переміщення» потягнути рамку з порожнього місця. Зліва направо (синя рамка) — повністю охоплені об'єкти; справа наліво (зелена) — об'єкти, яких торкається рамка. Shift додає до вибору. Група вибирається цілком; синя рамка має охопити всю групу.
5. Натиснути «Групувати», перемістити групу, перевірити Undo/Redo. Ctrl+C/Ctrl+V або кнопки копіюють вибране зі зміщенням 5 мм і зберігають внутрішні прив'язки розмірів. Ctrl+R або кнопка повертає виділення на 90°. Escape під час рамки або перетягування скасовує незавершену дію.
6. Інструментом «Розмір» обрати два кінці ліній/кути прямокутника/центри кіл або дві паралельні лінії (клацати посередині), потім перемістити напис і клацнути його положення. Точка + лінія дає перпендикулярну відстань. Для довжини однієї лінії: обрати її середину → Enter → розмістити напис. Помаранчевий маркер показує точку або ребро прив'язки. Вільні точки сітки теж допустимі, але не мають зв'язку з фігурою.
7. Виділити один об’єкт і змінити назву, координати, розміри, кути або текст на правій панелі. Для розміру вибрати тип і режим «Керувальний», ввести задане значення та застосувати. Перша вибрана геометрична опора лишається нерухомою; зміна разом із приєднаними вузлами та провідниками є одним кроком Undo. Односегментний провідник можна перетворити на графічну лінію і навпаки; Undo відновлює тип і належність до кола.
8. Зберегти .ecad, відкрити та змінити геометрію повторно: прив'язки збережені. Видалення опорної фігури видаляє її розміри тією ж операцією Undo.
9. Інструментом «Вузол» клацнути кінець, сегмент або перетин ліній. Точка прив'язується до точної геометрії; повторний клік не створює дубль. Перетин без точки лишається нез'єднаним.
10. Інструментом «Текст» клацнути місце, ввести напис і висоту. Подвійний клік редагує напис; Ctrl+R повертає його разом із виділенням.
11. Одна кнопка `Кут: …` циклічно перемикає вільний напрям і кроки `15°`, `30°`, `45°` для лінії та провідника, намальованих мишею. У режимі `Тип: провідник` клацнути початок і наступні точки траси. Для точного сегмента набрати довжину → Tab → будь-який кут → Enter; повторний Enter із порожніми полями завершує трасу. У режимі `Кут: вільно` кліки будують швидку ортогональну трасу, а Space перемикає напрям першого плеча.
12. Обрати IEC-символ у списку та натиснути «Символ». Подвійний клік по встановленому символу змінює позиційне позначення. Ctrl+R повертає символ і його контакти на 90°.
    Позиційне позначення є окремим текстом: його можна перетягувати незалежно від символу та редагувати тим самим діалогом тексту. При переміщенні символу позначення слідує за ним.
13. Для власного символу намалювати його лініями/прямокутниками, поставити вузли у місцях контактів, виділити все рамкою й натиснути «Створити символ…». Нове визначення з'явиться у списку та збережеться в поточному `.ecad`.
14. Кнопка «Перевірити схему» показує непідключені контакти, вільні кінці провідників і точні дублікати символів.
15. Якщо операція завершилася помилкою, програма показує повідомлення у нижньому рядку та записує технічні деталі. Кнопка «Журнал помилок» показує шлях і останні записи. Типовий шлях у Windows: `%LOCALAPPDATA%\ECAD\logs\ecad.log`; у Ubuntu: `~/.local/share/ECAD/logs/ecad.log`.
16. `P` або кнопка полілінії починає ламану. Кліки додають довільні вершини; довжина → Tab → кут → Enter додає точний сегмент; Enter із порожніми полями завершує. Після виділення вершини показуються маркерами й перетягуються мишею. У панелі властивостей координати всіх вершин можна редагувати рядками `X; Y`.
17. `A` або кнопка дуги підтримує два сценарії: початок → проміжна точка → кінець; або центр → радіус → Tab → кут дуги → Enter, де напрям курсора задає початковий кут. Радіус, початковий кут і кут дуги редагуються у властивостях.
18. Команди `⌇`, `⌫` і `⇥` відповідно розбивають сегмент, обрізають частину прямої до вибраної межі та продовжують вибраний кінець до межі. Для обрізання/продовження спочатку клацнути цільову пряму, потім межу.
19. Кнопка `▤` відкриває редактор бібліотек. Натисни `Додати приклади`, щоб отримати дві готові демонстраційні бібліотеки, або послідовно створи бібліотеку, тип, сімейство і варіант. Клацання на рівні відкриває його властивості. Табличні поля вводяться по одному запису в рядку, а формат колонок показано безпосередньо над полем. Пошук перевіряє назви, виробника, серію, артикул, конфігурацію, параметри, контакти й фізичні виконання.
20. Для символу, пов’язаного з моделлю пристрою, панель властивостей показує бібліотеку, тип, сімейство, виробника, серію, артикул, номінал, конфігурацію, параметри й кількість контактів. Там само можна вибрати сумісний варіант і одне з його фізичних виконань.
21. У групі `Аркуші` кнопка `+` додає сторінку, `✎` задає A4/A3, орієнтацію, рамку, зони та штамп, а `×` видаляє поточну сторінку. Щоб створити міжсторінковий зв’язок, виділи один елемент, натисни `⇄`, перейди на інший аркуш, виділи цільовий елемент і знову натисни `⇄`. Повторне натискання `⇄` для вже зв’язаного елемента видаляє зв’язок.
22. Виділи провідник, щоб у властивостях змінити номер кола, опис, потенціал, клас сигналу, колір і переріз. Номер показується безпосередньо над провідником. Кнопка `⚡` відкриває навігатор пристроїв, кіл, клемників і кабелів та запускає автонумерацію.
23. Відкрий `Projects/complete-electrical-demo.ecad`: у ньому є два аркуші, автомат QF1, реле KM1 з котушкою і контактом, перетворювач U1, двигун M1, клемник X1, кабель W1, призначені жили та міжсторінковий зв’язок.

Формат файлу оновлено до версії 12. Файли версій 1–11 читаються; для старих символів і провідників автоматично створюються пристрої, функції та стабільні електричні кола.

Колесо миші змінює масштаб навколо курсора; середня кнопка перетягує полотно. Escape або права кнопка скасовують незавершене малювання. На полотні працюють Delete, Ctrl+A, Ctrl+Z, Ctrl+Y, Ctrl+G та Ctrl+Shift+G.

## Автоматичні перевірки

Повна локальна перевірка у PowerShell: `./scripts/Verify.ps1`. Вона відновлює залежності, збирає Release, запускає checks і перевірку захисту пакетів; ненульовий exit code зупиняє сценарій. Такий самий сценарій додано у `.github/workflows/checks.yml` для Windows та Ubuntu 24.04 зі stable .NET 10. Результати локального та віддаленого прогонів наведені у звіті приймання 0.18.

За поточним рішенням користувача сумісність зі старими версіями не є вимогою; розширення міграцій відкладено. Наявні перевірки залишені.

Для зміни кола клеми або жили відкрий `⚡` → `Призначення`, вибери запис і коло, натисни `Застосувати`. `Без призначення` знімає зв’язок. Перед розділенням кола зніми всі його призначення, зміни провідники та признач потрібну гілку повторно. Зміни підтримують Undo/Redo; це редактор призначень, а не всіх параметрів кабелю.

```sh
dotnet run --project tests/ECAD.Checks/ECAD.Checks.csproj --no-restore
```

Release-перевірка охоплює 123 сценарії geometry/domain, persistence, integration і headless UI та окрему перевірку пакування. Це не замінює ручну перевірку desktop UI на Ubuntu. Докази й межі — [приймання 0.18](docs/RELEASE-0.18.md).
