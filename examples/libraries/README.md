# Приклади бібліотек ECAD

Ці файли демонструють можливості модульного каталогу версії 0.14. Дані мають навчальний статус: артикули починаються з `DEMO`, а номінали й габарити потрібно звіряти з офіційним каталогом перед використанням у реальному проєкті.

- `iec-automation-demo.ecadlib` — автоматичні вимикачі 1P, 3P і 4P, кілька виробників/серій, реле AC/DC, відкриті та обмежені поля конфігурації, спільні параметри, контакти і DIN-виконання.
- `drives-and-motors-demo.ecadlib` — частотні перетворювачі різної потужності й живлення, двигун із двома механічними виконаннями та ANSI-реле.

У програмі ці самі дані можна додати кнопкою `Бібліотеки пристроїв` (`▤`) → `Додати приклади`. Окремий файл імпортується кнопкою `Імпорт…`. Після імпорту всі записи можна редагувати, копіювати, шукати й повторно експортувати.
